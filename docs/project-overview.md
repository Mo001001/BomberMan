
# BomberMan Project Overview

## 1. Project Introduction

BomberMan is a Java-based game project inspired by the classic Bomberman game.

The main objective is to allow players to navigate the game environment, place bombs, and eliminate enemies while avoiding explosions.

## 2. Project Background

This project is based on an existing BomberMan source code repository.

Our team uses the original source code as the starting point for studying the software structure, understanding the game implementation, and practising collaborative software development.

## 3. Technology Stack

- Programming Language: Java
- Build Tool: Gradle
- Version Control: Git
- Collaboration Platform: GitHub

## 5. Version Control Strategy

Our team uses Git and GitHub to manage the project.

The main collaboration workflow includes:

1. Clone the shared repository.
2. Create an individual branch.
3. Make changes independently.
4. Commit and push changes.
5. Create a Pull Request.
6. Review and merge changes into the main branch.

## 6. Baseline Management

The original imported project is preserved as the initial baseline.

The Git tag `assignment1-baseline` identifies this baseline version and provides a reference point for future project changes.

## 7. Project Objectives

- Understand the existing BomberMan source code.
- Analyse the software structure and game execution flow.
- Practise Git and GitHub collaboration.
- Use AI tools to assist source code analysis and verify their explanations.
